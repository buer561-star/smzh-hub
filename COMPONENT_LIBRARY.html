Zins-Verlaufs-Chart (NEU — redaktionelle Datenfigur)

Statisches Inline-SVG, EINE Datenreihe, keine JS-Lib (Contract §7). Abgegrenzt von No-Go §5.3 (kein generischer/3D-/Torten-/Balken-Chart): eine reduzierte Zeitreihe im Stil einer .art-fig – dezente Achsen, Linie in --teal, Flaeche in --lblue, Quellen-figcaption wie .art-fig figcaption.
Klassen: .v5-ratechart · .v5-rc-fig · .v5-rc-svg · .v5-rc-area · .v5-rc-line · .v5-rc-axis · .v5-rc-grid · .v5-rc-dot · .v5-rc-lbl (-x/-y).
Wichtig: die folgenden Stuetzpunkte sind Demonstrations-Geometrie zur Skalierung — die realen Datenpunkte liefert das editorial (WP2); in der finalen Figur keine erfundenen Werte.

Wie haben sich die Zinsen entwickelt?

Eine Zeitreihe als faktischer Anker – neutraler Datenblock, kein CTA.

Skalierungs-/viewBox-Spezifikation — fuer den builder & das editorial 
viewBox        : 0 0 720 320  (Koordinatenraum, responsiv ueber width:100%;height:auto)
Plot-Flaeche   : x 56..680 (Breite 624), y 28..272 (Hoehe 244)
Y-Achse (Demo) : 0 % bei y=272, Max 3 % bei y=28  =>  px_pro_prozent = 244 / 3 = 81.33
                 y(wert%) = 272 − wert% * 81.33      (Max-% an die Datenlage anpassen)
X-Achse        : n Jahresstuetzpunkte gleich verteilt:
                 x(i) = 56 + i * (624 / (n−1))       (Demo n=6 -> Schritt 124.8)
Reihe          : genau EINE polyline.v5-rc-line; Flaeche path.v5-rc-area zur Grundlinie
                 (… L letzterX,272 L ersterX,272 Z) geschlossen.

Regeln (Contract §7.4):
 - genau 1 Datenreihe; mehrere Reihen => mehrere getrennte <figure>.
 - kein JS, keine Chart-Lib, keine Tooltips; Achsen dezenter als die Linie.
 - figcaption mit Quellenangabe Pflicht; Labels ohne Versalien.
 - Datenpunkte vom editorial — bis dahin deklarierter Platzhalter, KEINE erfundenen Werte.
